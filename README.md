# Smart Expense Tracker API

A REST API built with **FastAPI** (Python) for managing personal expenses. Expenses are persisted to a local JSON file — no database required.

## Features

| Endpoint | Method | Description |
|---|---|---|
| `POST /expenses/` | Create | Add a new expense |
| `GET /expenses/` | Read | List all expenses (optionally filter by `?category=`) |
| `GET /expenses/search?q=` | Read | Search expenses by keyword in title or category |
| `GET /expenses/totals` | Read | Overall + per-category spending totals |
| `GET /expenses/monthly` | Read | Month-by-month spending summary |
| `GET /expenses/{id}` | Read | Fetch a single expense by UUID |
| `DELETE /expenses/{id}` | Delete | Remove an expense by UUID |

**Bonus features implemented:** keyword search, monthly summary endpoint, and full OpenAPI/Swagger docs (auto-generated by FastAPI at `/docs`).


Interactive docs: **http://localhost:8000/docs**  
OpenAPI schema: **http://localhost:8000/openapi.json**

## Quick API tour

### Add an expense

```bash
curl -X POST http://localhost:8000/expenses/ \
  -H "Content-Type: application/json" \
  -d '{"title": "Coffee", "amount": 4.50, "category": "Food", "date": "2024-07-15"}'
```

### View all expenses

```bash
curl http://localhost:8000/expenses/
```

### Filter by category

```bash
curl "http://localhost:8000/expenses/?category=Food"
```

### Search by keyword

```bash
curl "http://localhost:8000/expenses/search?q=coffee"
```

### Get totals

```bash
curl http://localhost:8000/expenses/totals
```

### Monthly summary

```bash
curl http://localhost:8000/expenses/monthly
```

### Delete an expense

```bash
curl -X DELETE http://localhost:8000/expenses/<id>
```

## Data model

```json
{
  "id":       "uuid-v4-string",
  "title":    "Coffee",
  "amount":   4.50,
  "category": "Food",
  "date":     "2024-07-15"
}
```

- `id` is generated server-side (UUID v4)
- `amount` must be > 0, stored rounded to 2 decimal places
- `date` must be a valid ISO 8601 date (`YYYY-MM-DD`)
- `title` and `category` are trimmed of leading/trailing whitespace
